# HTML タグ補完拡張 仕様書

## 目的

HTML の開始タグ入力では閉じタグを挿入せず、`</` の入力で対応する閉じタグを自動挿入する。

## 対象範囲

- 対象言語: HTML
- 対象ファイル: `.html`、`.htm`、`.shtml`
- JSX、TSX、Vue、Svelte は対象外
- `h1`、`h2` などの開始タグ候補を含む既存の HTML 言語サーバー補完は維持する

## 振る舞い

### 開始タグ

- `<p>` を入力しても、拡張機能は `</p>` を自動挿入しない。
- `<h` などから表示される HTML 言語サーバーの候補は、既存どおり表示する。
- 通常の入力、候補選択、HTML 言語サーバーの補完機能には介入しない。

### 閉じタグ

- `<` の直後に `/` を入力したとき、対応する閉じタグを自動挿入する。たとえば `<p>text<` で `/` を入力すると `<p>text</p>` になる。
- 複数の未閉鎖タグがある場合は、最も内側のタグを閉じる。
- 対応する開始タグがない場合は、`/` のみを入力する。
- HTML の void 要素と自己終了要素は閉じタグの対象にしない。
- コメント、doctype、属性値、raw text 内では自動挿入しない。
- `>` 入力時の自動閉じは無効にし、`</` 入力時の自動閉じのみ有効にする。

## 実装方式

- 既存の HTML 拡張と同じ `html` 拡張 ID、HTML Tree-sitter 文法、`vscode-html-language-server` を使う。
- ワークスペース設定を既存値から読み込み、`html.autoClosingTags` のみ `false` に固定する。
- 他の HTML Language Server 設定は保持する。
- `</` に対する直接挿入は Zed エディター本体の入力処理で行う。HTML Language Server の通常のタグ候補はそのまま維持する。

## 受け入れ条件

1. `<p>` を入力したとき、結果が `<p>` であり、自動で `</p>` が追加されない。
2. `<h` 入力時に HTML の見出し候補が従来どおり利用できる。
3. `<p>text<` の位置で `/` を入力すると `<p>text</p>` になる。カーソルは閉じタグの後ろに置く。
4. フォーマッター、ホバー、HTML/CSS の既存 Language Server 機能に影響しない。
5. ユーザー設定の `html.autoClosingTags` が `true` でも、自動閉じタグは無効になる。

## Pacman 更新の制約

Zed 本体のソース変更だけでは、公式リポジトリのバイナリには反映されず、`pacman -Syu` 後に機能が維持されることも保証できない。更新後も使うには、この変更を含む Zed パッケージを更新ごとにビルドしてインストールする必要がある。パッケージの置き換えやシステムへのインストールは、ユーザーの確認なしに行わない。

## ローカル開発

Zed の Extensions ページから `Install Dev Extension` を選び、このフォルダーを指定する。ローカル版は `html` 拡張を置き換えるため、元の HTML 拡張に戻す場合は dev extension を無効化または削除する。
